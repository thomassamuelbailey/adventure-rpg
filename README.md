# Adventure RPG V1

My first C# console RPG built while learning programming fundamentals.

## Features

- Health system
- Gold system
- Random treasure chests
- Mimic encounters
- Goblin battles
- Town with healer
- Multiple player choices
- Game over system

## Built With

- C#
- Programiz Online C# Compiler

## What I Learned

- Variables
- User input
- if / else statements
- while loops
- Random events
- Nested menus
- Basic game design

## Development Notes

This project was built by me while learning C#.

I used ChatGPT as a learning tool to:
- Help explain programming concepts
- Identify syntax and logic errors I couldn't spot myself
- Suggest improvements and new features
- Explain compiler error messages
- Learn better coding practices and problem-solving techniques

All code was written, tested, and modified by me as part of the learning process.
